# 📅 孕期台历

一个为孕期妈妈设计的轻量级孕周计算工具，手机端可用、离线可用、支持 B 超校准。

---

## ✨ 功能特性

### 核心功能
- **孕周计算**：根据末次月经第一天，自动计算任意日期对应的孕周
- **孕周反推**：输入孕周（如 12周+3天），查询对应的自然日期
- **B 超校准**：支持根据医生 B 超结果调整孕周基准，所有计算自动同步

### 日历视图
- **台历式月历**：直观显示每日信息，点击任意日期查看当日详情
- **孕月配色**：10 个孕月独立配色（相邻色相差异大），一眼分辨孕期阶段
- **孕月起始角标**：每孕月第一天右上角显示孕月编号
- **农历显示**：每个日期显示对应农历（初一显示月份）
- **二十四节气**：自动标注节气日期（1900~2100 年天文算法）
- **节假日 / 调班**：联网自动获取国务院节假日数据，含放假和调休补班
- **今日高亮**：今天的日期用橙色圆环标记

### 孕期提示
- **本周孕期提示卡片**：可折叠，点击展开
  - 胎儿发育
  - 胎儿大小
  - 孕妈要做的事（每周 3~5 条）
- **饮食核心要点**：
  - 分阶段显示（孕早期 / 孕中期 / 孕中晚期）
  - 提前 2 周预告下一阶段要开始补充的补剂
  - 全程分组提示：🍽️ 宜吃 / ⚠️ 少吃 / 🚫 禁吃 / 💡 注意
- **孕周百科浮层**：可查看孕 3~40 周全部内容 + 完整饮食指南

### 其他
- **自动保存**：末次月经、校准天数、B 超记录等自动保存到本地
- **跨设备可用**：部署到 GitHub Pages，手机浏览器访问，可添加到主屏幕
- **离线可用**：所有计算本地完成，无需网络（节假日首次加载后缓存）

## 🚀 快速开始

### 方法一：直接打开 HTML 文件

1. 下载 `index.html` 到本地
2. 用浏览器打开即可使用（手机端建议用 Safari / Chrome）
3. 首次使用请设置"末次月经第一天"

### 方法二：部署到 GitHub Pages（推荐）

1. Fork 或创建新仓库
2. 上传 `index.html` 到仓库根目录
3. 仓库 → Settings → Pages → Branch 选择 `main` + `/ (root)` → Save
4. 等待 1~2 分钟，访问 `https://你的用户名.github.io/仓库名/`
5. **添加到手机主屏幕**：
   - iOS Safari：分享按钮 → 添加到主屏幕
   - Android Chrome：菜单 → 添加到主屏幕

### 方法三：在 iPhone 上打开本地文件

由于 iOS 系统限制，直接点击 HTML 文件通常不会在 Safari 中打开。推荐使用以下方式：
- **Documents by Readdle**（免费 App）：内置浏览器，可直接打开 HTML
- **微信文件传输助手**：将文件发送到手机，用"其他应用打开"选择浏览器
- **AirDrop**：从 Mac 传输到 iPhone 后用 Safari 打开

## 📖 使用说明

### 1. 设置末次月经

打开工具后，在"原始末次月经第一天"输入你的末次月经日期（格式 YYYY-MM-DD）。这是整个工具的基准起点。

### 2. 查看今日孕周

顶部"今日孕周"卡片会自动显示：
- 今天对应的孕周（如 孕12周+3天）
- 预产期（末次月经 + 280 天）
- 距预产期天数

### 3. 点击日历查看任意日期

点击台历上任意日期，下方会显示该日期的：
- 农历
- 孕月
- 节假日 / 调班
- 节气
- 距预产期天数

点击"今天"按钮可回到当前月份，并收起日期详情。

### 4. 孕周校准（B 超修正）

如果医生根据 B 超重新确定了孕周：
1. 展开"孕周校准"卡片
2. 输入 B 超日期和当时 B 超显示的孕周
3. 点击"计算校准结果"，预览调整后的基准
4. 确认无误后点击"应用校准"

也可以手动输入要调整的天数（正数 = 基准后移，负数 = 基准前移）。

### 5. 反推日期

在"查某孕周是哪一天"卡片输入孕周和天数，即可查询对应日期。

### 6. 查看孕期百科

点击"本周孕期提示"卡片底部的按钮：
- **🍎 完整饮食指南**：19 条饮食建议 + 注意事项
- **📚 孕3~40周全览**：每周胎儿发育、大小、孕妈要做的事

## 🛠 技术说明

### 技术栈
- **纯前端**：单个 HTML 文件，无任何依赖
- **原生 JavaScript**：无框架，无构建步骤
- **localStorage**：本地数据持久化
- **Fetch API**：节假日数据联网获取

### 数据来源

| 数据 | 来源 |
|---|---|
| 农历 | 内置算法（1900~2100 年） |
| 二十四节气 | 天文算法（回归年长度 + 节气偏移表） |
| 节假日 / 调班 | [NateScarlet/holiday-cn](https://github.com/NateScarlet/holiday-cn)（自动同步国务院公告） |
| 孕期知识 | 参考主流孕期指南、产检手册整理 |

### 节假日数据 CDN

代码内置 3 个 CDN 源，自动按顺序尝试：
1. `cdn.jsdelivr.net`
2. `fastly.jsdelivr.net`
3. `raw.githubusercontent.com`

任一可用即可加载数据。若全部失败，日历仍可使用，仅不显示节假日标记。

### 浏览器兼容性

- ✅ iOS Safari 12+
- ✅ Android Chrome 70+
- ✅ 桌面端 Chrome / Firefox / Safari / Edge

## ⚠️ 注意事项

1. **本工具仅用于日期与孕周计算参考**，不替代医生的诊断和产检建议
2. **孕周校准**只调整本工具的计算基准，实际孕周及预产期请以产检医生的判断为准
3. **节假日数据**来自第三方开源项目，联网自动获取，可能与最新官方公告有延迟
4. **本地数据**保存在浏览器 localStorage 中，清除浏览器数据会丢失设置
5. **孕期知识**内容供参考，具体饮食、运动、用药请遵医嘱

## 🔧 常见问题

### Q1：点击日期显示"早于有效末次月经"？

说明你点击的日期早于设置的末次月经日期，无法计算孕周。这是正常的边界处理。

### Q2：为什么今日孕周和点击今天的孕周不一致？

可能原因：
- 手机系统日期是今天，但"今日孕周"卡片用的是**系统当前日期**
- 点击日历上的"今天"格子，用的是**同一日期**，二者应该一致
- 若不一致，请刷新页面重试

### Q3：修改末次月经后，之前的校准还在吗？

在的。修改末次月经会保留校准天数。如需重置，先点击"清除校准"。

### Q4：孕 40 周之后为什么没有孕月颜色了？

孕期范围是 40 周（280 天）。超过预产期后，日历不再显示孕月颜色，属正常设计。

### Q5：节假日数据加载失败怎么办？

- 检查网络连接
- 等待 1~2 分钟后刷新页面
- 若所有 CDN 均不可用，日历仍可使用，仅不显示节假日标记

### Q6：手机浏览器打不开本地 HTML 文件？

iOS 系统限制，无法直接点击 HTML 文件用 Safari 打开。建议：
- 部署到 GitHub Pages（推荐）
- 使用 Documents by Readdle 等第三方文件管理器
